### Python 虚拟环境初始化

- 修复 `-env` 错把可执行文件路径当作虚拟环境路径的问题，正确读取紧随参数的值，优先于 `VIRTUAL_ENV`，拒绝空值、缺值和重复参数；环境必须有 `pyvenv.cfg` 和解释器，不再静默回退或原样记录路径。

### 连接订阅与后台文本发送

- 新增 `shenbot_api.watch_ica_connection()`：首份当前快照及事件驱动变化订阅，QQ 离线、主连接重连和插件生命周期变化均唤醒，无需等待第一条聊天；最多 64 个订阅，可显式关闭，不新增状态轮询。
- 订阅提供绑定插件代、连接代和账号的 `send_text`，整个操作共享最多 5 秒的绝对期限，复用在途限额与卸载排空；旧代、旧连接和错账号拒绝，只报告 Socket.IO 受理，不保证 QQ 送达，不自动重发。
- 修正 ICA 关闭事件为锁定依赖的 `Event::Close`，禁用依赖内置自动重连，由宿主唯一监督重连并递增连接代；迟到状态事件与旧连接守卫不能复活或关闭新连接。

### ica 2.0.6 / oicq Bridge 能力对齐

- 以本地 Icalingua++ 的 Socket.IO + oicq 实际注册、位置参数和 ACK 为基准，协议版本继续为 **2.26.7**；不跟进 Milky/OneBot，不把 native 的桌面 UI 或未接通事件当成服务端能力。
- 消息反序列化兼容字符串和数字 ID，畸形输入返回错误而不 panic；补齐 legacy 单附件、多媒体顺序/尺寸、64 位文件大小、引用和扩展字段。完整规范化 `raw_data` 与可选协议节点链 `raw_msg` 分开提供。
- 修复 Python `send_raw_message` 的实际发送合同：`content` 为 JSON 字符串，始终携带 `at=[]`；非法或空节点链在发送前抛出 `ValueError`，不再静默吞错。
- 新增 Python `emit_event` / `request_event`，复用现有主连接，区分仅发送受理与真实 ACK，并提供独立超时；已知无 ACK、fileMgr 命名空间或当前 Bridge 未实现的调用会明确报错，未知扩展事件仍可使用。
- 新增可返回消息对象的历史分页、关键词/发言人/上下文/图片查询，以及联系人、系统申请历史、合并转发展开 API；查询结果合并进按房间隔离的有界缓存，`/bot-fetch` 不再只记录条数，历史查询不重放新消息或自动回复 hook。
- Python 消息对象新增媒体、时间、@、代码卡片、引用、撤回资料和结构化 JSON 快照；发送消息新增 `at` 读写、`new_message`，并提供 `to_forward_node` / `send_merged_forward`。没有原始节点链的合并转发明确降级不可重建的资源，不伪造普通文件资源。
- 消费 `renewMessage` 和 `renewMessageURL`，将 QQ 撤回映射到原有删除 hook 并有界去重；新增 `on_ica_message_updated(client, room_id, message_id, patch)` 与 `on_ica_bridge_event(client, event, args)`。更新房间已读及原始房间/分组快照，登录挑战交给插件处理而不转储到日志。
- 新增 SHA-256 分片上传、普通文件发送、群文件上传及独立鉴权的 fileMgr 请求；完成整文件校验才提交，只有幂等上传分片自动重试，不重试不确定的 QQ 发送。普通文件 API 不接受图片/音频 MIME，请使用媒体接口，或显式以 `application/octet-stream` 作为文档发送。
- 明确修正已读能力说明：当前独立 oicq Bridge **没有注册 `reportRead`**，旧 `report_read` 仅保留发送事件的兼容行为，不表示 QQ 收到上报；首屏 `fetchMessages` 的 Bridge 内部上报仍存在。清 Bridge 未读数和 QQ 已读回执是两类操作。`stopFetchingHistory` 未注册，`getPrivateFileUrl` 在 oicq 显式未实现，均不会伪装成功。
- 同步独立 `ica-plugin` 仓库的 2.0.6 类型、新 hook 契约、实际管理员查询/媒体插件和离线测试；旧消息 getter 与既有插件继续兼容。
- 更新 21 个现有兼容依赖，包括 `serde_json 1.0.154`、`toml 1.1.8`、`hyper 1.12.0`、`tokio-util 0.7.20`，并加入直接 `sha2 0.10.9`；rust-socketio Git revision 保持不变。传递 `sha2 0.11.1` 将最低 Rust 要求提高到 **1.88**；Python requirements 已允许最新版，Python 3.12 下最新依赖组合解析通过，未改动实际插件环境。
- 独立 Bridge 的 Socket.IO 接收上限同步调整为 4 MiB，以接收既有 512 KiB 分片的 JSON 字节数组封装；使用旧默认 1 MB 上限的服务端需同步此配置，分片大小和事件参数保持不变。
- 补充 Windows 构建指南：先初始化 Visual Studio x64 C++ 环境；遇到 `lib.exe` 无法打开用户 Temp 临时文件的 `LNK1104` 时，可仅在当前进程将 `TEMP/TMP` 切换到项目构建目录，保持依赖更新且不改动系统环境或 ACL。运行中的 Bot 占用默认可执行文件时，使用独立输出目录验证新 release，不自动停机或替换。
