# 0.9 更新日志

## Unreleased

### ica 2.0.5 / Icalingua++ 2.26.8

- 对照本体 2.26.8 与 ica-native 0.1.20/0.1.21，仅同步 bot 适用的 **oicq Bridge** 协议与接口，不跟进 Milky/OneBot；Socket.IO 兼容协议更新为 **2.26.7**（与服务发布版本区分）。
- 修复 `sendAddRequest` 把好友申请当作加群申请解析的问题；继续使用 `on_ica_join_request` hook，好友申请的 `group_id` 为 `None`，`group_name`/`tips` 缺失时为空字符串；补充 `source`、`self_id`、`age` 和 `sex`。插件应先判断 `request_type`，不要直接对可空群号做运算。
- Rust / Python 新增 `handle_request`（friend/group，批准或拒绝）、`report_read`（主动 QQ 已读上报）与 `get_nt_pic_url_by_file_id`（12 秒 ACK 超时）；已读上报不自动修改 Bridge 会话未读数。
- 修正戳一戳参数：群聊向 oicq 传正群号，私聊的两个参数均为会话对方 ID；拒绝 0、无效用户及绝对值溢出的目标。
- `SendMessage` / Python `IcaSendMessage` 新增 `set_audio` 和 `set_audio_fid`：分别发送内嵌 Base64 语音或复用协议资源；关闭贴纸标记，内嵌语音沿用一次性 HTTP token，不走群文件上传。录音/播放 UI 不移植到 bot，音频编码/转码依赖 oicq Bridge 及 FFmpeg。
- 认证日志区分服务版本和协议版本，不输出签名 challenge；兼容缺失版本信息的旧 Bridge，损坏 challenge 或私钥返回明确错误并交给连接监督器，不再索引越界或 panic 后一直等待。
- 处理 `dbUpgradeProgress` 并仅记录升级计数；好友/群申请失败和未知事件不再输出原始内容；非字符串通用事件不再导致 panic。
- HTTP 媒体发送增加 30 秒超时，错误日志去掉带一次性 token 的 URL；返回成功只表示 Bridge 经 HTTP 202 接收或 Socket.IO 请求已发送，不保证 QQ 最终送达，不自动重试不确定的发送。
- 同步 `ica-plugin/ica_typing.py` 的类型声明，并为群门卫补充缺失群号保护。

### ica 2.0.1

> 添加了 `shenbot_api` 模块

- `def python_plugin_path() -> str`
  - 用于获取 Python 插件的目录

- `def python_config_path() -> str`
  - 用于获取 Python 插件配置的目录

> 添加了 `Room` 相关的 api

- `IcaStatus` 添加了 `rooms(self) -> list[IcaRoom]` 方法
  - 用于获取当前所有的房间

- 添加了 `IcaRoom` 类
  - 用于表示一个房间
  - `room_id -> int` 群号 (i64)

  - `def is_group(self) -> bool` 是否为群聊
  - `def is_chat(self) -> bool` 是否为私聊

  - `room_name -> int` 群名 (String)
  - `unread_count -> int` 未读消息数 (u64)
  - `priority -> int` 优先级 (u8)
  - `utime -> int` 最后活跃时间 (unix sec * 1000)

  - `def new_message_to(self, content: str) -> IcaSendMessage`
    - 用于创建一条指向这个房间的消息

> 添加了 Ica 侧的相关配置获取

- `IcaStatus` 添加了 `admins(self) -> list[UserId]` 方法
  - 用于获取当前所有的管理员

- `IcaStatus` 添加了 `blocked(self) -> list[UserId]` 方法
  - 用于获取当前所有的被屏蔽的人
